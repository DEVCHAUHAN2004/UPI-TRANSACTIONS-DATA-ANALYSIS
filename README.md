## 📌 Project Overview

This project is an **interactive UPI Transaction Data Analysis Dashboard** built using **Microsoft Power BI**.

The dashboard transforms UPI transaction data into meaningful business insights through interactive visualizations, slicers, filters, trend analysis, banking analysis, customer segmentation, merchant analysis, and detailed transaction reporting.

The project focuses on understanding:

- 💰 Balance trends
- 📈 Monthly transaction patterns
- 🏦 Sending & receiving banks
- 🏙️ City-wise transactions
- 💳 Payment methods
- 🛍️ Merchant activity
- 👥 Customer demographics
- 📱 Device usage
- 🎯 Transaction purposes
- 🔄 Transaction types
- 💱 Currency-wise analysis

# 🎯 Business Objectives

The main objective of this project is to analyze UPI transaction data and convert it into actionable business insights.

### Key questions addressed:

- 💰 How does the balance change month by month?
- 📅 Which months have higher or lower activity?
- 🏦 Which banks are involved in transactions?
- 🏙️ How does transaction activity vary by city?
- 💳 Which payment methods are being used?
- 🛍️ Which merchants receive transaction activity?
- 🔄 What are the major transaction types?
- 👥 How does behavior vary across age groups?
- 🚻 How does transaction behavior vary by gender?
- 📱 Which devices are used for transactions?
- 🎯 What are the major transaction purposes?
- 💱 How do amounts and balances vary by currency?
